Use an Obsidian checkbox to track study progress, not proof that a command has passed. Every tutorial includes objectives, prerequisites, explained examples, expected results, practice, troubleshooting, five knowledge questions with collapsible answers, cleanup, and official references.

Examples target Ubuntu and Bash. They are documentation only: no tools were installed, containers started, workflows triggered, images published, or servers deployed while writing these notes. Local-development demonstrations are separate from CI and authorized server operations. Check credentials, targets, costs, and destructive effects before trying an exercise.

The complete frontend release capstone assumes an existing application and provisioned target. It is not a claim that a production Laravel/React/MariaDB platform has been deployed or validated. Additional roadmap topics are marked planned in the subject question lists.
